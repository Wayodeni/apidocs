# Yaade

Yaade предоставляет веб-интерфейс для работы с HTTP-запросами, локальные учётные записи и общие коллекции. Nginx принимает HTTPS-запросы и передаёт их Yaade по внутренней сети Docker. Учётные записи и коллекции хранятся в томе `yaade-data`.

## Запуск

При первом запуске создайте `.env` из [шаблона с описанием переменных](.env.example). Команда подставляет случайный временный пароль.

```sh
(
  umask 077
  set -C
  yaade_initial_password=$(openssl rand -hex 24) &&
    sed "s/^YAADE_DEFAULT_PASSWORD=$/YAADE_DEFAULT_PASSWORD=$yaade_initial_password/" .env.example > .env
)
```

Для локального запуска сгенерируйте самоподписанный сертификат и ключ с помощью OpenSSL.

```sh
(
  umask 077
  mkdir -p certs && openssl req -x509 -newkey rsa:3072 -nodes -sha256 -days 365 \
    -subj '/CN=Yaade' \
    -addext "subjectAltName=${YAADE_TLS_SAN:-DNS:localhost,IP:127.0.0.1}" \
    -addext 'basicConstraints=critical,CA:FALSE' \
    -addext 'extendedKeyUsage=serverAuth' \
    -keyout certs/yaade.key -out certs/yaade.crt
)
(umask 077; mkdir -p logs/nginx)
docker compose up -d
```

Откройте [Yaade](https://127.0.0.1:9443) после добавления `certs/yaade.crt` в доверенные сертификаты браузера или ОС. При первом входе используйте `YAADE_ADMIN_USERNAME` и `YAADE_DEFAULT_PASSWORD` из `.env`. Смените пароль администратора в `Settings / Account` перед созданием учётных записей участников.

Запросы к `http://127.0.0.1:9339` и `http://127.0.0.1:9443` получают постоянное перенаправление HTTP 308 на `https://127.0.0.1:9443` с сохранением пути и параметров.

## Доступ команды

1. Укажите в `.env` адрес сетевого интерфейса сервера, например `YAADE_BIND_IP=192.168.1.10`. Порты задаются через `YAADE_HTTP_PORT` и `YAADE_HTTPS_PORT`. Чтобы браузер перенаправлял на HTTPS при открытии адреса без порта, задайте `YAADE_HTTP_PORT=80` и примените изменения командой `docker compose up -d`.
2. Перед генерацией сертификата задайте SAN с фактическим адресом, по которому участники будут открывать Yaade. Например, `export YAADE_TLS_SAN='DNS:localhost,IP:127.0.0.1,DNS:yaade.example.org,IP:192.168.1.10'`. Выполните команду генерации, затем `docker compose up -d`. После замены сертификата у работающего Nginx выполните `docker compose exec nginx nginx -g 'load_module modules/ngx_http_js_module.so;' -s reload`.
3. Передайте участникам публичный сертификат `certs/yaade.crt` по доверенному каналу. Для сверки отпечатка используйте `openssl x509 -in certs/yaade.crt -noout -fingerprint -sha256`. Храните `certs/yaade.key` на сервере.

Проверьте доступность HTTPS с проверкой сертификата и имени сервера.

```sh
curl --fail --location --cacert certs/yaade.crt http://127.0.0.1:9339/api/health
```

## Защита входа

После пяти отказов в течение 10 минут с первого отказа Nginx блокирует новые запросы `POST /api/login` с этого IP на 15 минут. Учитывается ответ Yaade `500` с сообщением `Unauthorized`. Успешный вход обнуляет счётчик ошибок. Во время блокировки Nginx возвращает `429` и указывает оставшееся время в секундах в заголовке `Retry-After`. Пользователи за общим IP делят лимит. Действующие сессии продолжают работать.

Каждое срабатывание записывается отдельной строкой JSON в `logs/nginx/login-blocks.log`. Запись содержит время, IP, тип события и время окончания блокировки. Для сброса всех блокировок выполните `docker compose restart nginx`. Файл журнала сохраняется на хосте.

## Общая коллекция

1. В `Settings / Users / Local` создайте отдельную учётную запись для каждого участника и укажите для них одну группу, например `api-team`.
2. В настройках коллекции добавьте `api-team` в поле `Groups` и сохраните изменения. Коллекцию можно создать в Yaade или импортировать из Postman.
3. Новые локальные пользователи входят с временным паролем `YAADE_DEFAULT_PASSWORD`. Каждый участник меняет его в `Settings / Account` при первом входе. Yaade использует этот временный пароль также при сбросе пароля администратором.
4. Пользователи редактируют одну серверную коллекцию. Чтобы увидеть сохранённые изменения коллеги в уже открытом интерфейсе, обновите страницу.

`docker compose down` останавливает сервис с сохранением тома. Флаг `-v` удаляет том вместе с учётными записями и коллекциями.

В Yaade зарегистрирован обход групповых прав для отдельных операций со скриптами со стороны авторизованных пользователей. Используйте один экземпляр для участников с общим уровнем доверия. [Описание проблемы](https://github.com/EsperoTech/yaade/issues/270)
